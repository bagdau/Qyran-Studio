# Qyran Studio API

FastAPI + PostgreSQL backend. API documentation becomes available at `http://localhost:8000/docs` after startup.

## Endpoints

- `GET/POST /api/v1/projects`
- `GET/PATCH/DELETE /api/v1/projects/{project_id}`
- `POST /api/v1/projects/{project_id}/scenes`
- `GET/POST /api/v1/assets`
- `DELETE /api/v1/assets/{asset_id}`
- `GET /health`
